# Shared Windows GUI prefixes

Named base-element and base-window fields in the original base implementations and their established GUI descendants. Candidate files are read before propagation; inheritance anchors include calls to original GUI constructors and inherited virtual-table references. Files without those anchors are excluded. Access widths restrict propagation to appropriate scalar, pointer, rectangle and flag-byte views. Widget-specific offsets beyond the common prefixes are not treated as inherited fields.

The 44-byte element prefix contains virtual table at zero, rectangle at four, interaction state at `0x14`, flags at `0x18`, element ID at `0x1C`, parent window at `0x20`, message handler at `0x24` and serial at `0x28`. A separate name describes byte one of the flags. The 108-byte window prefix adds a clipping rectangle at `0x2C`, drawing-order child list at `0x3C`, input-order child list at `0x50` and active child at `0x64`. The final DWORD at `0x68` remains unresolved. Physical models describe the prefixes and retain list storage as opaque bytes; they do not change ownership or construction.

Authoritative Windows evidence is `0047841B..00478B76`: construction, destruction, child-list operations, activation, input, drawing and base-element state. The original embedded window-vars constructor receives root `+0x2C` and constructs lists at relative `0x10/0x24`; the current private C++ helper takes the whole window and addresses the same absolute `0x3C/0x50`. Both lists are constructed before the original whole-region reset. That order, active-child transitions, reverse input ordering, forward draw ordering, virtual slot indices, message forwarding, hide flags, serial assignment/wrap and lifetime operations are preserved. Mac is used for existing class/method naming only.

Validation: exact staged baseline/final source comparisons, unchanged C++ tokens after constant substitution, 20 literal value/type pairs, 21 layout assertions and 736 decoded instruction byte comparisons with original `Game.exe`. All 307 production units pass Win32 `/Zs`; final affected units and private assertion units pass after the final naming changes. Five pre-existing GUI C4805 warnings remain. The companion CSV lists 337 named references. No build, tests or game execution was performed.

The committed change covers 40 source/header files, including the shared models/constants. An include-only candidate change was removed. The audit retains that file in its stage history, so its audited-file total is 41. Whole-source review, descendant-specific fields and explicit unresolved regions remain open.
