The complete 100-byte manager contains sector width/height, an owning sector allocation, an 84-byte active-loop list (count and ten ID/volume pairs), and the last landscape playback tick. A 56-byte sector has two separate lists, each containing a count and three ID/weight pairs. Pattern groups scan a 10×10 macro region with two triangles per point and normalize weights to percentages; landscape groups scan 20×20 micro points and retain their counts. The complete static ambient record is 5,488 bytes: 40-byte name, accumulated selection weight, sound count, and forty 136-byte waves. Pattern loops intentionally use the first wave ID (+168); landscape selection subtracts each wave's weight from the random remainder.
