## Exploration radius

[Human_SetupCurrentJobType](../src/C2HumanJobAccess.cpp) writes `ExplorationRadius` (+0xB7C); [walking](../src/C2HumanWalking.cpp) passes it to map exploration. Windows `0044AC97..0044ACD3` selects values at `004F3B8C/90/94/98`: scout **20**, hero **20**, other adult **10**, child **5**. These are map-point radii, not screen pixels or attack ranges. The user included the scout-radius **500** change in commit `dbf96ad`; this differs from the original Windows value.
