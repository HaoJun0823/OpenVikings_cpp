# Single-human selection window storage

The window's tab flags, collapse flags, checksum, rectangles, size calculation, height overrides, rebuild flag, preview/name children, trader route controls, configuration popup, experience page/table, tooltip handler and dynamic buttons now have named Windows offsets. Existing human and player allowance definitions replace remaining raw actor accesses in this window. Dynamic button entries and their distinct graphic/text command-data offsets are named separately.

Windows evidence: constructor and destructor `004AB7F1..004ABAA5`; tab reconstruction, route controls and experience initialization `004AE231..004AEED4`; tooltip/dynamic button helpers `004B9D0C..004BA053`. The Mac reference matches class/helper names only.

The full object occupies `0x3D78` bytes. State begins at `0x70`, with six enabled/collapsed flags, six rectangles and six height overrides. The preview/name and two route rows precede an 11-by-14 experience table. Tooltips at `0x39C` end at the dynamic-button handler at `0x3280`; that handler ends at the popup pointer at `0x3D74`. The embedded SVars constructor's tooltip offset is relative `0x32C`, not a root-object offset. The storage model keeps the base-window prefix and padding opaque and does not change runtime allocation or object construction.

Preserved: constructor-before-clear order, the 15,624-byte state reset, collapsed-tab persistence, forced layout rebuilds, experience filtering/sort order, compact trader rows, child deletion/recreation order, popup lifetime and message handling. Button entry activity still uses byte reads/writes inside its DWORD storage. Signed and unsigned inventory-condition offset variants retain their original literal types. No class/function was merged or runtime behavior intentionally changed.

Validation: exact staged source/token equivalence, 61 literal value/type pairs, 21 physical-layout assertions, Win32 `/Zs` for the production unit and private assertion unit, and 1,646 decoded instruction byte checks against original `Game.exe`. The companion CSV contains 152 named references. No build, tests or game execution. Remaining widget-specific fields and unrelated GUI windows are still review targets.
