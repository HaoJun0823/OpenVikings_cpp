# Logic map storage and serialized records

Named shared map dimensions/counts, both rectangles, continent count/table and known consumers across logic and engine bridges. `SLogicMapStorage` describes the existing 4,108-byte storage: four signed dimension words, two DWORD counts, two rectangles, three owned buffer pointers, continent count and 250 sixteen-byte continent records. Its final 44 bytes remain explicitly unclassified. The model does not replace the original raw storage or buffer ownership.

The macro point model is three bytes: pattern A, pattern B and height. The fourteen-byte micro point has object tag, an unclassified byte, four type-dependent payload bytes, continent/direction bytes, two exploration/fog words and walking/terrain flags. Payload aliases remain separate: a landscape player byte and a house ID can share offset four without sharing meaning. Saving/loading plane helpers and strides use the corresponding record definitions; engine-map records are not substituted with logic-map definitions.

Continent records name type, packed seed point, point count and the update-retention byte. Its trailing three bytes remain explicit. The source retains byte versus DWORD writes to the retention position, temporary IDs, queue-capacity placement, split/merge/remap phases and compaction restart behavior. Relevant area-search consumers reuse walking-direction/flag offsets; this does not change search cost, insertion or callback behavior.

Windows evidence: map initialization `004234C4..0042378A`, serialized field planes `00430420..00430C8F` and continent routines `00451503..00452B04`. Preserved: signed-word doubling and dimension mirrors, allocation/clearing/free order, retained payload bytes, mask widths, packing types, plane/chunk order, complete continent-prefix serialization, per-chunk pointer reloads, borrowed child-manager integration and existing search guards. Mac is a naming reference only.

Validation: exact staged source/token equivalence, 42 literal value/type comparisons, 33 physical size/offset assertions, eleven affected production units and the private assertion unit passing Win32 `/Zs`, and 2,730 decoded instruction byte comparisons with original `Game.exe`. The companion CSV lists 303 named references. No build, tests or game execution occurred. Remaining point-coordinate operands, pathfinder state and other unclassified map fields remain separate review targets.
