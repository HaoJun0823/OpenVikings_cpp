# Goods search, guide routing and production review

The goods-search block now uses named guide/network records, map-micro-point fields, construction-material columns, production sentinels and job-experience layouts. Guide creation/removal, reciprocal links, routing scratch ownership and search consumers share those names. All behavior comes from Windows; Mac declarations supply original function/class spelling only.

Windows evidence: Game.exe 0041B061..0041C0B4, 00447283..0044780D, 0045F17D..00460F28, 00442047..00442542, 0044B871..0044BA7A, 0045CA9A..0045CC92 and 0041AE53..0041B061. The existing typed static-actor data describes the same weapon/experience offsets used by the Windows access routines.

Guides occupy 388 bytes: allocated byte at 0, player at 4, ID at 8, link-system ID at 12, revision at 16 and packed position at 20. Eight distance/guide-ID links occupy 0x38..0x77, count is at 0x78 and 66 goods counters start at 0x7C. Bytes 0x18..0x37 remain explicitly unresolved. The manager contains its link-system counter, forty 124-byte distance buckets and an owned visited array at 0x1364. Bucket records contain a count followed by thirty pointer slots; original searches do not gain an invented overflow check.

Map offset 2 is a union: byte reads use `ObjectData`, while WORD reads identify a guide ID. Offset 4 is a house ID in house branches and a signed landscape player in landscape branches. These meanings are kept separate rather than assigning one actor type to the whole region. The complete map-micro-point layout remains a later review target.

The complex goods-search record remains 668 bytes with 66 wanted goods, ten landscape candidates, two house candidates and three guide candidates. Search order, stopping distance, random calls and first-hit preference remain unchanged. House-demand paths still keep their distinct failure side effects and reservation order. A consumer with zero demand retains its original true return without writing destination coordinates. Guide lookup in the complex path still reads position before checking the failed ID. Reciprocal-link removal retains its original unconditional count decrement.

Production counter 11 is named `Infinite`; rotation, rounding, finite decrement and notifications keep their original order. Experience categories 1/2/3/6/7 now identify their human fields by category number; weapon-type names have not been guessed. Static experience records have named first/second good, factor and base retry columns. Signed division, DWORD overflow and unsigned saturation are retained. This reviews production/efficiency and shared goods paths; the remaining capability/unlock and job-specific routines are still part of the overall source review.
