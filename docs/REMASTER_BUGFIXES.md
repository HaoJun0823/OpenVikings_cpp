## Viking wooden-spearman sleep animation

RM029 corrects the original Viking wooden-spear sleep graphic reported on October 17, 2026. The user confirms the defect occurs in the original game. Windows assets establish the data error: `data/engine2d/inis/mapmoveableanimations/animations.cif` contains a 78-entry progressive list for tribe 1/job 32/action 8, but the iron-spear entry (job 33) uses the same `human_man_Warrior_spear_sleep` body sequence with 237 entries. Both jobs inherit `viking_soldier_sleep`, whose logic duration is 237 ticks in `data/logic/atomicanimations/atomicanimations.cif`. The wooden list omits exactly 159 copies of resting frame 36 before the final get-up transition. Inserting them produces the iron-spear list byte-for-byte as DWORD frame IDs.

Windows loader `0048C3C6..0048C3F9` copies the supplied progressive list without repairing it. Frame selection `0049506F..00495083` scales the frame-list index over the total logical duration, matching the current C++ helper. Thus the short list stretches each transition frame over roughly three ticks instead of one and allocates little time to the resting pose. This finding is supported by Windows data and code, not by Mac behavior or an assumed runtime-migration regression.
