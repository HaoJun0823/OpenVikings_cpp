## Branch policy

Its code and [original-behavior register](RECONSTRUCTION_NOTES.md) remain unchanged. The register is historical evidence, not an active remaster status list. The register contains 97 OB entries and 156 OA entries, not 253 independently reproduced bugs. Existing reconstruction corrections and intentional usability changes are tracked separately in [gameplay issues](GAMEPLAY_RENDERING_BUG_REVIEW.md). This ledger does not retroactively relabel those as original bugs.

All network-related comparison rows below are analysis only and deferred, including host-input loss, stability, transfer size, version checks, multiplayer music/options and logging. No network implementation was changed. The [player changelog](../CHANGELOG.md) describes the completed source changes; it is not a claim that the whole historical register is resolved.

Six modules explicitly name bug fixes. Their overlap with our records is:

- Marker allocation is a direct code-path overlap with OA130: the original reserves a slot and rejects a valid border point before initialization. The community report identifies a border-marker crash, including AI guide use. This same rejection is present in our Windows reference.
- Particle access outside the map is already recorded in the gameplay review, outside the OB/OA catalog. Our checked accessor prevented the invalid read; RM005 below completes retirement of the escaped particle.
- School is related to OA163, but the mechanisms differ. The community patch disables general job/good eligibility based on the current training counter. OA163 concerns independent current-job working-experience events during schooling. RM001 fixes the former; the subsequent RM023 separately suppresses current-job working experience during training.
- Vehicle-builder freeze, attack-radius freeze and host input loss are not separately identified as exact defects in our OB/OA catalog. Broad task/path/network observations cover their surroundings but are not proof that those exact bugs were already listed.
- None of these six modules directly fixes OB089's player-count/message-length copy error, OB044/OB090's event-counter errors or the other specific OB audio/CRT findings. Shared subsystem names are not an exact overlap.
