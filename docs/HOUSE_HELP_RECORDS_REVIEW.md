# Building selection and help window records

Building selection now names the eleven enabled/collapsed tab flags, checksum, rectangles, computed size, height overrides, layout invalidation, preview pointer, selected stock good, page, seven stock pages and both embedded handlers. The physical Windows model is 15,584 bytes. Tooltip construction receives the embedded state at root +112: its relative +664 is the root tooltip at +776. The final stock page begins at +720. Padding and the unused descriptor word remain explicit; no unsupported purpose is assigned to them.

The help window model is 4,176 bytes: selected page, hypertext frame, 100 eight-byte building type/stage entries, building help strings and selected index, 100 goods, goods help strings and selected index, miscellaneous count/strings/index, hypertext child and dynamic button handler. Engine building type/stage/tribe fields are named at the proven consuming accesses without claiming a complete engine type reconstruction. Building and single-good sort records have distinct names despite both beginning at zero.

Help command names previously described the wrong domains. IDs 10011..10014 select/navigate buildings, 10015 opens a good referenced by a building, 10016..10019 select/navigate goods, and 10020..10023 select/navigate miscellaneous entries. 20000 opens building information; 20001 opens good information. Their values and branch behavior are retained. A building collapsed-stock-tab offset also no longer uses the unrelated signed-byte-maximum constant.

Windows evidence: `004A6F10..004A9785` and `004C31CA..004C4855`. Preserved: construction before clearing embedded state, frame registration order, saved collapse flags, inclusive hit edges, sort ties and NaN exclusion, height invalidation, child deletion before rebuilding, command and callback order, partial stock page updates, string ownership and destruction order, navigation wrap to the list, hyperlink callback behavior and the miscellaneous page's existing goods-string guard.
